The licence

The engine is open source, and this page is honest about what a licence is. There is nothing technical to enforce: the engine is free and unlimited, and a key does not gate a run. What a key does is name the licensee on the run record, which is what matters when an auditor asks who produced a number.

What is free, forever

  • The engine: the byte-exact gate, the three compute tiers, the C ABI, the MCP server, and the judge harness. AGPL-3.0-or-later, at any scale. No row cap, no key, no form, no telemetry. Use it, modify it, run it; if you offer a modified version over a network, share it.
  • The parsers: the copybook parser and the DB2 importer. Apache-2.0. Embed them freely.
  • The sample migration: Apache-2.0, with the gate wired into its CI.
  • The evidence: every run record behind every published number.

Clone it at github.com/bylazora. Give your agents the rule pack and they know the invariants before they draft a line.

What we actually do

How buying works today

There is no checkout on this page yet. Email contact@bluebirdadvisory.com.au with the organisation name to license and we issue a key: an Ed25519-signed token naming that organisation and its expiry. One command installs it:

bylazora-core licence set <key>

The key is verified locally against a published public key, so the engine stays air-gapped. Renewal is a reissue rather than a subscription: the next year's key arrives before the current expiry passes. Card checkout is coming; we would rather say that plainly than describe a button that is not there.

The key, honestly described

The key is an Ed25519-signed token carrying your organisation and its expiry. The binary verifies it locally against a published public key: no network, no telemetry, no activation server, so the engine runs air-gapped. It is an artefact, not a gate. The engine runs identically without one, at any scale, and an expired key does not stop a run - deliberately, because anything else would make installing a key worse than not installing one. What the key buys is legal rather than mechanical: the right to use the engine where AGPL is not acceptable, and a run record that names you on every keyed run.

The engine is free. The run is how we get paid.
